# 17 — Creator Dashboard & Analytics

## Purpose

Give a Creator a backend-authoritative overview of their courses, learner progress, assessment outcomes, frequent errors, skill gaps, and course-improvement recommendations.

## Existing routes

- `/creator/analytics` — all creator-owned courses
- `/creator/analytics/[courseId]` — one backend course, using its numeric ID

## API integration

API Creator sessions use:

- `GET /api/creator/dashboard` — complete dashboard report
- `GET /api/creator/dashboard?course_id={id}&date_from=YYYY-MM-DD&date_to=YYYY-MM-DD` — filtered report
- `GET /api/creator/dashboard/export?format=csv` — authenticated backend CSV export

The frontend maps its 7, 30, and 90 day selectors to `date_from` and `date_to`; **All time** omits date filters. The course selector receives only course IDs returned by the same report. CSV is downloaded from the backend with the current bearer token.

## API-mode data

The dashboard shows only fields returned by the API:

- course count, learner count, completed learners, completion rate, and average assessment score
- per-course learner/completion/assessment metrics
- learner progress and assessment scores
- common-error topics and skill-gap counts
- backend course-improvement insights

The current API does not return lifecycle state, pre/post comparison, practical pass rate, verified-skill count, funnels, retry rates, or per-content metrics. API mode does not fill those sections from the demo fixture.

## States

- Loading report
- Creator authorization/network failure with Retry
- No creator courses
- Filtered empty learner/error/gap/insight sections
- Ready report and backend CSV export

## Demo behavior

Demo and bypass sessions keep the existing local analytics engine and preview-query states. An API session renders the backend report instead.

## Test order

1. Login as `creator@skillsync.local` in API mode.
2. Create at least one course under that Creator account.
3. Open `/creator/analytics`.
4. Select a course or date range, open a numeric course detail page, then click **Export CSV**.

Analytics records are deterministic mock analytics generated by the backend for creator-owned courses; they reset when the backend process resets.
